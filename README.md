# Tate Script

Tate Scriptは、日本語の脚本を縦書きで執筆し、PDFとして出力するVS Code拡張機能です。原稿はUTF-8のテキストファイルとして保存し、通常のテキストエディタやGitと組み合わせて管理できます。

## 主な機能

- 新しい作品のフォルダーと必要なファイルを一括作成
- 日本語IMEに対応した縦書き編集と、横書き原稿の縦書きプレビュー
- 柱・ト書き・セリフの判定、字下げ、禁則処理、手動改ページ
- 作品名・作者名・登場人物・ページ設定の編集
- A4横・B5横のPDF生成と、保存前のPDFプレビュー
- 縦書きの表紙・登場人物表と、本文のページ番号の生成

## 動作環境

| 項目 | 必要な環境 |
| --- | --- |
| OS | Windows |
| エディタ | VS Code 1.146.0以降 |
| PDF生成 | Microsoft Edge |
| 原稿の差分・履歴管理 | Gitを利用する場合はGitのインストールが必要 |

PDF生成では、インストール済みのMicrosoft Edgeをバックグラウンドで起動します。PDFプレビューは拡張機能に同梱したPDF.jsで表示します。

## 新しい脚本を書き始める

1. `Ctrl+Shift+P` でコマンドパレットを開き、`Tate Script: 新しい作品を作成` を実行します。
2. 作品用フォルダーの保存先を選び、作品名を入力します。
3. 選んだ保存先の中に作品用フォルダーが作られ、縦書きエディタが開きます。
4. 本文を入力し、画面上部の「保存」ボタンで原稿を保存します。
5. 作者名や登場人物を設定するときは、原稿を開いた状態で `Tate Script: 作品設定を開く` を実行します。

初期設定はA4横・20字×20行です。空の原稿と、登場人物が登録されていない状態で始まります。

作品用フォルダーは入力した作品名から作ります。フォルダー名に使えない文字は `_` に置き換えます。同名のファイルやフォルダーがある場合は、別の保存先または作品名を選んでください。

## 作品のファイル構成

```text
作品フォルダー/
├── screenplay.txt
├── project.json
└── characters.json
```

| ファイル | 内容 |
| --- | --- |
| `screenplay.txt` | 脚本本文。ファイル名は固定です |
| `project.json` | 作品名、作者名、用紙サイズ、字数・行数 |
| `characters.json` | 登場人物の名前、説明、掲載順 |

作品はフォルダーごとに管理します。作品名とフォルダー名は異なっていても使えます。表紙や作品選択に表示する作品名には、作品設定の値を使います。作品名が空欄の場合は `screenplay.txt` を表示します。

作成済みの作品を再び編集するときは、その作品フォルダーをVS Codeで開きます。`screenplay.txt` を開いてから `Tate Script: 縦書きエディタを開く` を実行してください。

## 原稿の書き方

```text
○公園（夕）
美咲、ベンチに座っている。

美咲「もう来ないと思ってた」
健太「ごめん。少し迷ってた」
```

| 種別 | 記法と表示 |
| --- | --- |
| 柱 | 行頭を `○` または `〇` にします。字下げせずに表示します |
| セリフ | `美咲「こんにちは」` のように書きます。折り返しの2行目以降は1字下げます |
| ト書き | 動作や情景などの文章です。折り返した行も含めて3字下げます |

閉じるかぎ括弧まで入力されたセリフを判定します。入力途中で括弧が閉じていない文章は、ト書きとして表示される場合があります。

改行と空行は入力した位置と数を保ちます。空行を増やす場合は、自分で改行を入力してください。組版上の折り返しや字下げは表示時に適用され、原稿ファイルには入力した文章を保存します。

任意の場所でページを区切るには、縦書きエディタ上部の「手動改ページ」ボタン、または `Tate Script: 手動改ページを挿入` を使います。カーソルがある原稿行の直前に改ページが入ります。

横書きで編集しながら版面を確認する場合は、通常のテキストエディタで `screenplay.txt` を開き、`Tate Script: 縦書きプレビューを開く` を実行します。縦書き画面には未保存の編集も反映されます。

## 作品設定と登場人物

`Tate Script: 作品設定を開く` で、作品名、作者名、用紙サイズ、1行の字数、1ページの行数を変更できます。「作品・ページ設定を保存」で適用します。

登場人物は「登場人物を追加」から名前と説明を入力し、「登場人物を保存」で保存します。登場人物表は登録順に掲載します。登録がゼロ件の場合は、PDFを表紙と本文の構成で出力します。

| 設定 | 対応する値 |
| --- | --- |
| 用紙サイズ | A4横、JIS B5横 |
| 1行の字数 | 10〜40字 |
| 1ページの行数 | 10〜40行 |

標準の20字×20行では、文字サイズは次のとおりです。字数・行数を変更すると、本文と登場人物表の文字サイズも調整されます。

| 項目 | A4横 | B5横 |
| --- | --- | --- |
| 本文、登場人物の名前・説明 | 14 pt | 12 pt |
| 登場人物表の見出し | 16 pt | 14 pt |

登場人物の名前は太字です。表紙のタイトルは30 pt、作者名は22 ptで、それぞれ縦書きで配置します。

## PDFを確認して保存する

1. 原稿、作品設定、登場人物の変更を保存します。
2. `Tate Script: PDFをプレビュー` を実行します。
3. 表紙・登場人物表・本文の版面を確認し、「PDFを保存」を押して保存先を選びます。

直接PDFを保存する場合は、`Tate Script: PDFを出力` を実行します。

PDFは、対象作品が決まった直後にディスクから読み込んだ保存済みデータで生成します。編集内容をPDFに反映するには、保存してからPDF生成を再実行してください。

本文のページ番号は `1/12` のように左下へ表示します。表紙と登場人物表は本文のページ数に含めません。

複数作品がある場合は、操作中の原稿や縦書き画面に紐づく作品を使います。対象を特定できないときは、作品の選択画面が開きます。

文字が用紙から見切れる可能性を検出した場合は警告を表示します。警告後も保存できますので、プレビューで該当ページを確認してください。

## コマンド一覧

`Ctrl+Shift+P` でコマンドパレットを開き、`Tate Script` と入力するとコマンドを検索できます。

| コマンド | 操作 |
| --- | --- |
| `Tate Script: 新しい作品を作成` | 作品用フォルダーと3ファイルを生成して縦書きエディタを開く |
| `Tate Script: 縦書きエディタを開く` | 原稿を縦書きで編集する |
| `Tate Script: 縦書きプレビューを開く` | 横書き原稿を縦書きで確認する |
| `Tate Script: 作品設定を開く` | 作品・ページ設定と登場人物を編集する |
| `Tate Script: 手動改ページを挿入` | カーソルがある原稿行の直前でページを区切る |
| `Tate Script: PDFをプレビュー` | 保存済みの作品をPDFにして確認する |
| `Tate Script: PDFを出力` | 保存済みの作品をPDFにして指定先へ保存する |

## 困ったとき

- 原稿を開くよう案内された場合は、`screenplay.txt` を開いてからコマンドを実行してください。
- PDF生成時にEdgeを起動できない場合は、Microsoft Edgeがインストールされていることを確認してください。
- 設定ファイルのエラーが出た場合は、表示されたファイルと項目を確認して修正してください。
- 設定画面を開いた後にJSONファイルを別の画面で変更した場合は、その変更を保存してから設定画面の「再読み込み」を押してください。
